# UART + Error Detection System
Project 4 - Design of a UART transceiver system with integrated error detection.

## Verilog Source Code:
* `baud_gen.v`: Baud rate generator.
* `uart_tx.v` & `uart_rx.v`: UART transmitter and receiver modules.
* `error_encoder.v` & `error_decoder.v`: Error calculation and detection modules.
* `uart_system_top.v`: Top-level system integration module.
* `tb_uart_system.v`: Verification testbench.
